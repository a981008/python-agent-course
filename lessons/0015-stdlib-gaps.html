三、logging：别再用 print 调试（5 分钟）

PYTHON — 官网 11.5"日志记录"
import logging
logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s %(levelname)s %(name)s: %(message)s",
)
log = logging.getLogger(__name__)

log.debug("循环第 %d 次", i)     # 默认不输出；改 level=DEBUG 才出现
log.info("已加载 %d 条", n)
log.warning("配置缺失，使用默认值")
log.error("写文件失败")

# 比 print 强在哪：
#   ① 分级——上线时把 DEBUG 关掉，不用删代码
#   ② 可重定向到文件（filename="app.log"），不污染 stdout
#   ③ 带时间、模块名；多模块时知道是谁打的
#   ④ % 占位是惰性格式化，级别关闭时不拼接字符串

# Agent 场景：工具调用失败写 warning，重试写 info，绝不 print 到模型输出里
第 5 课练习里的 log 是个列表变量，用于断言 finally 是否执行；它不是 logging 模块。那是教学替身，到这里换成真家伙。

四、五个小而高频的工具（5 分钟）

PYTHON — 官网 11.2 / 11.6 / 11.7 / 10.10
# ① string.Template：Prompt 模板首选
from string import Template
tpl = Template("你好，$name，你有 $count 条消息")
tpl.substitute(name="小王", count=3)      # '你好，小王，你有 3 条消息'
# 为什么不直接用 f-string？LLM Prompt 里常含 JSON 的 { }，
# Template 只认 $var，不会和大括号打架。

# ② weakref：缓存不拴住对象
import weakref
registry = weakref.WeakValueDictionary()
registry["agent"] = some_agent
# 别处不再强引用 some_agent 时，它自动从注册表消失——
# 适合"按名字找实例"的注册表，避免循环引用泄漏。

# ③ bisect：有序序列二分定位
import bisect
xs = [1, 3, 5, 7]
bisect.bisect_left(xs, 5)                 # 2（插入位置）

# ④ heapq：TopK 不用全排序
import heapq
heapq.nlargest(3, [5, 1, 9, 3])           # [9, 5, 3]
# sorted(...)[-3:] 也行，但 nlargest 只维护 k 个元素的堆，大列表更省。

# ⑤ timeit：别靠感觉比较快慢
import timeit
timeit.timeit("[x*x for x in range(100)]", number=10000)

def parse_cli(argv):
    p = argparse.ArgumentParser(description="统计词频")
    p.add_argument("path")
    p.add_argument("-n", "--top", type=int, default=5)
    args = p.parse_args(argv)
    return args.path, args.top

def render_prompt(template, **kwargs):
    return Template(template).substitute(**kwargs)

def top_k(nums, k):
    if k <= 0:
        return []
    return heapq.nlargest(k, nums)

六、检索练习：先答后看（关补全）




  
Q1 · argparse 相比手写解析 sys.argv 最大的好处是？

  
  
  
  
argparse 是标准库：add_argument 声明参数后，它负责类型转换（type=int）、必填校验、未知选项报错和自动生成的 --help。手写 split 会把这些边界全漏掉。






  
Q2 · Prompt 模板为什么推荐 string.Template 而不是 f-string？

  
  
  
  
LLM Prompt 经常包含 JSON 示例，里面有大量花括号。f-string 会把它们当成插值表达式导致语法错误；Template 只认 $var，两者互不干扰。如果必须同时用花括号和插值，才考虑 .format() 并转义。






  
Q3 · 从大列表里取前 3 名，heapq.nlargest 相比完整 sorted 的优势是？

  
  
  
  
sorted 要对全部元素排序 O(n log n)；nlargest 只维护一个大小为 k 的堆，复杂度约 O(n log k)。k 远小于 n 时优势明显。小列表两者差别不大。
