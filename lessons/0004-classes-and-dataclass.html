第 4 课 · 类与 dataclass：self、@dataclass 与 Protocol

Mission: Python（Agent 开发与面试算法） · 预计 30 分钟 · 关掉 AI 补全再开始

本课的 win：不看资料写出「手写类 + @dataclass」两种写法的同一份数据模型，说清 @dataclass 帮你自动生成了什么；再认识 Protocol——LangChain/LangGraph 源码里 Model、Tool、Retriever 全是它。

一、心智模型：class 就是 Java class，少了三样东西（3 分钟）

Python 的类和 Java 的类结构同源：属性、方法、构造、继承都有。但少/换了三样东西，先对齐：

二、普通类：__init__、self 与 __repr__（6 分钟）

JAVA — 一个消息类
public class Message {
    private final String role;
    private final String content;

    public Message(String role, String content) {
        this.role = role;
        this.content = content;
    }

    @Override
    public String toString() {
        return "Message(" + role + ", " + content + ")";
    }
}
PYTHON — 同一件事
class Message:
    def __init__(self, role: str, content: str):
        self.role = role          # self.xxx 直接创建实例属性，无需先声明字段
        self.content = content

    def __repr__(self) -> str:    # 对应 toString()
        return f"Message({self.role}, {self.content})"

三个要点：

① __init__ 是初始化不是构造——对象在它之前已经创建好了（由 __new__ 管，日常不用碰），你只负责把属性挂上去；

② self 是真实参数：m = Message("user", "hi") 之后，解释器只是替你把实例传进方法——m.role 背后就是 self.role；

③ __repr__ 对应 toString()：调试打印、日志、报错信息全靠它，写类必配。

三、@dataclass：record + Lombok 合体（8 分钟）

上面的 Message 有 80% 是样板代码——Java 用 Lombok 或 record 消灭它，Python 用 @dataclass：

PYTHON — 三行顶手写十行
from dataclasses import dataclass

@dataclass
class Message:
    role: str
    content: str

它自动生成了三样东西：__init__（按字段顺序）、__repr__（可读打印）、__eq__（按字段值比较）。Java record 自动带的 equals/toString，是同一件事。

其余不常用选项（slots、kw_only 等）：
参考 · 全语法速查表 · 类与面向对象

第 3 课的坑在这里变本加厉：普通函数写 def f(items=[]) 是埋雷，而 dataclass 直接不让你埋——类定义当场抛 ValueError: mutable default。可变默认值必须显式声明"每次实例化都新建"：

可变默认值的正确姿势
from dataclasses import dataclass, field

@dataclass
class AgentState:
    session_id: str
    messages: list[str] = field(default_factory=list)   # 每个实例一个新列表
    done: bool = False

default_factory=list 的意思是：每次创建实例时调用 list() 生成新列表——这正是第 3 课哨兵值 items=None 的声明式版本。

其它常用项速记：

写法效果Java 对应
@dataclass(frozen=True)字段不可变record
field(default=...)不可变默认值构造参数默认值
field(default_factory=list)可变默认值无（Java 允许共享，是坑）
dataclasses.asdict(obj)整棵转 dictJackson 序列化的前置

逐个展开说。frozen=True 在类定义时就声明"实例不可变"——之后任何字段赋值都抛 FrozenInstanceError，错误暴露在第一时间而不是某个深夜的脏数据；附带效果是 dataclass 会生成 __hash__，实例能进 set、当 dict 的键（Java 的 record 本身就不可变，所以天然有这性质）。field(default=...) 和直接写默认值等价，只是显式一点；真正不可替代的是 default_factory（上面刚讲过）。asdict(obj) 把实例整棵转成 dict——嵌套的 dataclass 字段也会递归转换，是接 JSON 序列化的前置步骤。

PYTHON — frozen 与 asdict 实测
from dataclasses import dataclass, asdict

@dataclass(frozen=True)          # 不可变 + 自动获得 __hash__
class Config:
    model: str
    temperature: float = 0.7

c = Config(model="glm-4")
# c.model = "other"    ← FrozenInstanceError：赋值当场被拒
d = asdict(c)          # {'model': 'glm-4', 'temperature': 0.7}
print(hash(c) == hash(Config(model="glm-4")))   # True：值相同 → 哈希相同

四、继承与 super()（5 分钟）

PYTHON
class Animal:
    def __init__(self, name: str):
        self.name = name

    def speak(self) -> str:
        return f"{self.name} 会叫"

class Dog(Animal):                    # Java: class Dog extends Animal
    def speak(self) -> str:
        return f"{self.name} 汪汪"

语法差异只有三处：父类直接写进括号（extends → 括号）、没有访问修饰符、重写同名方法即可（没有 @Override 注解——"我确实覆盖了父类方法"要靠自己核对拼写，面试手写时留意）。super().方法() 调父类版本，和 Java 相同。

Python 支持多继承（Java 没有），方法查找顺序叫 MRO——知道这个概念即可；实际 Agent 项目里更推荐组合优于继承，真正要继承的场景大多换成了下面的 Protocol。

五、Protocol：不写 implements 的接口（8 分钟）

Java 里实现接口必须 implements 声明。Python 的 Protocol 反过来：不声明继承，只要方法长得像就算实现（结构化类型，鸭子类型的形式化）：

PYTHON — 定义接口与"隐式实现"
from typing import Protocol, runtime_checkable

@runtime_checkable
class ChatModel(Protocol):
    def complete(self, prompt: str) -> str: ...   # 方法声明体就是 ...

class FakeModel:                                   # 注意：没有继承 ChatModel！
    def complete(self, prompt: str) -> str:
        return "fake: " + prompt

isinstance(FakeModel(), ChatModel)   # True——结构匹配即实现

这就是 Agent 框架的接口模式：ChatModel、Tool、Retriever 定义成 Protocol，任何第三方类"长得像"就直接能用，测试时写个 Fake 实现零耦合。两个注意点：

① @runtime_checkable 只让 isinstance 可用（只检查方法名存在，不检查签名）；只给类型检查器用、不做运行时判断的话可以不加。

② 方法声明的函数体写 ...（Ellipsis）——Python 惯用的"此处无实现"，对应 Java 接口方法的分号。

六、检索练习：先答后看（关补全）

Q1 · @dataclass 自动生成哪三个方法？

对应 record/Lombok 自动生成的部分。__hash__ 需要 frozen=True 才有（可变对象做字典键有隐患）；Python 里 getter/setter 没必要，直接用属性。

Q2 · dataclass 字段写成 messages: list[str] = [] 会怎样？

dataclass 检测到可变默认值立即拒绝——比普通函数的可变默认参数坑暴露得更早。default_factory=list 表示每次实例化调用 list() 新建，是第 3 课哨兵值写法的声明式版本。

Q3 · Protocol 与 Java interface 最大的差别是什么？

这正是鸭子类型的形式化。加 @runtime_checkable 后运行时也能 isinstance（只查方法名存在性）；选项 a 是 ABC 的做法，选项 c 错——@runtime_checkable 就是干这个的。
