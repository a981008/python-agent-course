Mission: Python（Agent 开发与面试算法） · 预计 35 分钟 · 关掉 AI 补全再开始

本课的 win：面试手写不再靠灵感——先做数据结构选型，再套五个模板（哈希 / 双指针 / 滑动窗口 / 二分 / 栈），每题都能说清复杂度。验收：五个模板各手写一遍并通过边界测试。

一、选型：拿到题先问三件事（3 分钟）

对照 — Java 数据结构 → Python 对应物HashMap / HashSet        →  dict / set
TreeMap / TreeSet        →  sortedcontainers（第三方）；标准库用 bisect + list
ArrayDeque               →  collections.deque
PriorityQueue            →  heapq（最小堆；取负数模拟最大堆）
Arrays.binarySearch      →  bisect.bisect_left / bisect_right
Stack（Deque 当栈）       →  list（append / pop）
对照 — 先问三件事，再动手① 需要"按值快速找到位置/次数"？      →  哈希表 O(1)
② 需要"有序 + 找边界/前 k"？          →  排序 / 二分 / 堆
③ 需要"最近一个未处理元素"？          →  栈 / 单调栈
④ 需要"连续区间满足某条件"？          →  滑动窗口 / 前缀和

面试里写不出最优解，通常不是语法问题，而是没先判断题型。把上面四行背下来，比刷十道同型题更有用。

复杂度速记：哈希 O(1) 查询；二分 O(log n)；堆取前 k 个 O(n log k)；排序 O(n log n)；双指针/滑窗 O(n)。

二、模板 1 · 哈希表：空间换时间（4 分钟）

PYTHON — 两数之和（Hot 100 第 1 题）def two_sum(nums, target):
    seen = {}                      # 值 -> 下标
    for i, x in enumerate(nums):
        need = target - x
        if need in seen:
            return [seen[need], i]
        seen[x] = i
    return []

# 例：[2, 7, 11, 15], target=9 → [0, 1]
# 关键：先查后存，避免同一个元素用两次
PYTHON — 计数与去重：哈希表的另外两种常见形态from collections import Counter
Counter("abracadabra").most_common(2)      # [('a', 5), ('b', 2)]

seen = set()
for x in nums:
    if x in seen:
        return True                        # 找重复
    seen.add(x)

# 判断"是否存在/出现过" → set；需要"值 → 附加信息" → dict
# 字符串题注意：sorted(s) 可做异位词比较，但 O(n log n)；计数数组可到 O(n)

三、模板 2 · 双指针：把两重循环压成一层（3 分钟）

PYTHON — 有序数组两数之和 II（返回下标，1-based）def two_sum_sorted(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo < hi:
        s = nums[lo] + nums[hi]
        if s == target:
            return [lo + 1, hi + 1]
        if s < target:
            lo += 1                     # 和太小，左指针右移
        else:
            hi -= 1                     # 和太大，右指针左移
    return []
PYTHON — 原地去重 / 移动零：快慢指针def remove_duplicates(nums):
    if not nums:
        return 0
    slow = 0
    for fast in range(1, len(nums)):
        if nums[fast] != nums[slow]:
            slow += 1
            nums[slow] = nums[fast]
    return slow + 1                     # 新长度

# 快指针探索，慢指针写结果；原地修改，O(1) 额外空间

双指针适用前提：数组有序，或问题允许"左右夹逼/读写分离"。无序数组强行双指针通常需要先排序，而排序可能破坏下标语义。

四、模板 3 · 滑动窗口：连续子串/子数组（4 分钟）

PYTHON — 最长无重复字符子串（Hot 100 第 3 题）def longest_unique(s):
    last = {}                           # 字符 -> 最近下标
    left = best = 0
    for right, ch in enumerate(s):
        if ch in last and last[ch] >= left:
            left = last[ch] + 1         # 收缩到重复字符右边
        last[ch] = right
        best = max(best, right - left + 1)
    return best

# "abcabcbb" → 3（"abc"）
# 为什么是 last[ch] >= left：窗口外的旧位置不影响当前窗口
PYTHON — 定长窗口：长度固定时用"进出各一次"def max_sum_window(nums, k):
    window = sum(nums[:k])
    best = window
    for i in range(k, len(nums)):
        window += nums[i] - nums[i - k]     # 进一个、出一个
        best = max(best, window)
    return best

滑窗的骨架永远一样：右指针扩张，条件破坏时左指针收缩，每步更新答案。变长窗口问"最长/最短"，定长窗口问"固定长度内的最值"。

五、模板 4 · 二分：边界是灵魂（4 分钟）

PYTHON — lower_bound：第一个 >= target 的位置def lower_bound(nums, target):
    lo, hi = 0, len(nums)            # 区间 [lo, hi)
    while lo < hi:
        mid = (lo + hi) // 2
        if nums[mid] < target:
            lo = mid + 1
        else:
            hi = mid
    return lo                        # 可能等于 len(nums)

# [1, 3, 5, 7] target=5 → 2；target=4 → 2；target=99 → 4
PYTHON — 标准库：bisect 直接给边界import bisect
xs = [1, 3, 5, 7]
bisect.bisect_left(xs, 5)        # 2  第一个 >= 5
bisect.bisect_right(xs, 5)       # 3  第一个 > 5
bisect.insort(xs, 4)             # 有序插入，保持 O(n) 移动（查找 O(log n)）

写二分只记两句话：循环不变量决定区间开闭，边界更新决定会不会死循环。[lo, hi) 配 hi = mid 是最好记的一套；写完用空数组、单元素、全小于、全大于四种输入自测。

六、模板 5 · 栈、单调栈与堆（5 分钟）

PYTHON — 有效括号（栈的经典入口题）def valid_parens(s):
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []
    for ch in s:
        if ch in "([{":
            stack.append(ch)
        elif not stack or stack.pop() != pairs[ch]:
            return False
    return not stack
PYTHON — 单调栈：每日温度（下一个更大元素）def daily_temperatures(temps):
    ans = [0] * len(temps)
    stack = []                       # 存下标，对应温度单调递减
    for i, t in enumerate(temps):
        while stack and temps[stack[-1]] < t:
            j = stack.pop()
            ans[j] = i - j
        stack.append(i)
    return ans
PYTHON — heapq：前 k 大（TopK）import heapq

heapq.nlargest(3, [5, 1, 9, 3])         # [9, 5, 3]
heapq.nsmallest(2, [5, 1, 9, 3])        # [1, 3]

# sorted(...)[-k:] 也对，但要排全部 O(n log n)；
# nlargest 只维护 k 个元素的堆，约 O(n log k)。

栈题判断信号："最近未匹配"、"下一个更大/更小"、"嵌套结构"。单调栈在入栈前弹掉破坏单调性的元素，每个下标最多进出一次，整体 O(n)。

def two_sum(nums, target):
    seen = {}
    for i, x in enumerate(nums):
        if target - x in seen:
            return [seen[target - x], i]
        seen[x] = i
    return []

def longest_unique(s):
    last, left, best = {}, 0, 0
    for right, ch in enumerate(s):
        if ch in last and last[ch] >= left:
            left = last[ch] + 1
        last[ch] = right
        best = max(best, right - left + 1)
    return best

def lower_bound(nums, target):
    lo, hi = 0, len(nums)
    while lo < hi:
        mid = (lo + hi) // 2
        if nums[mid] < target:
            lo = mid + 1
        else:
            hi = mid
    return lo

def valid_parens(s):
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []
    for ch in s:
        if ch in "([{":
            stack.append(ch)
        elif not stack or stack.pop() != pairs[ch]:
            return False
    return not stack

def top_k(nums, k):
    if k <= 0:
        return []
    return heapq.nlargest(k, nums)

八、检索练习：先答后看（关补全）




  
Q1 · "两数之和"要求返回下标，最优解为什么是哈希表？

  
  
  
  
对每个 x 先查 target-x 是否出现过，再记录 x 的下标。空间换时间：一次遍历、O(n) 时间、O(n) 空间。排序 + 双指针也能做，但会丢原始下标。






  
Q2 · 滑动窗口里，右指针什么时候该收缩左边界？

  
  
  
  
右指针负责扩张、左指针负责恢复合法性。以"最长无重复子串"为例：遇到已出现且在窗口内的字符，就把左边界跳到它上次出现位置的右边。






  
Q3 · 二分查找里 while lo < hi 与 hi = mid 的写法，通常用于？

  
  
  
  
边界二分的关键是区间语义：[lo, hi) 半开区间，nums[mid] < target 时 lo = mid+1，否则 hi = mid。循环结束时 lo 就是第一个满足条件的位置。






  
Q4 · 括号匹配、表达式求值、每日温度，共同适合的数据结构是？

  
  
  
  
这类问题都有"最近未匹配/最近的更大元素"特征，后进先出正好对应。单调栈则是栈里维持单调性，用来一次扫描解决"下一个更大元素"。
