二、切片：Java 要写循环的事，Python 一个方括号（5 分钟）

更多切片细节：
参考 · 全语法速查表 · 切片 
PYTHON — seq[start:stop:step]，含头不含尾
letters = ['a', 'b', 'c', 'd', 'e', 'f']
letters[1:4]        # ['b', 'c', 'd']      → list.subList(1, 4)
letters[-2:]        # ['e', 'f']           负索引从尾部数（Java 没有）
letters[::2]        # ['a', 'c', 'e']      步长 2
letters[::-1]       # 反转，等价 Collections.reverse
nums = [1, 2, 3]
copy = nums[:]      # 浅拷贝整个序列（切片总是产生新对象）
letters[10:]        # [] —— 切片越界不抛异常（Java 直接 IndexOutOfBounds）
nums[1:3] = [20, 30]   # 切片赋值：直接改片段

三条记忆点：① 含头不含尾（和 subList 一样）；② 负索引从尾部数，取尾不再手算 size-1；③ 越界不炸——切片是"取窗口"，窗口外面没有就给空。字符串、元组同样支持。

注意 nums[:] 是浅拷贝：只复制最外层，嵌套列表里层还是同一个对象——和 Java new ArrayList<>(src) 一个脾气。

三、闭包与 LEGB：Python 的作用域规则（5 分钟）

Java 匿名类只能捕获 final 变量；Python 闭包能读写外层变量——但有个坑。变量查找顺序叫 LEGB：Local（本函数）→ Enclosing（外层函数）→ Global（模块）→ Builtins（内建）。

PYTHON — 查找就近遮蔽，赋值才要声明
x = "global"
def outer():
    x = "enclosing"
    def inner():
        x = "local"        # 就近遮蔽，不改外层
        return x
    return inner()

# 闭包写状态：内部函数引用外层变量，外层函数返回它
def make_counter():
    count = 0              # 状态藏在闭包里
    def inc():
        nonlocal count     # ★ 没有它，count += 1 会创建新局部变量！
        count += 1
        return count
    return inc

c = make_counter()
c(); c()                   # 1, 2 —— 每次调用 make_counter 得到独立计数器

nonlocal 是 Java 程序员最容易漏的字：闭包里读外层变量不需要声明，写（赋值）才需要。global 是另一层——模块级变量。

经典坑：循环变量被闭包共享：

PYTHON — 三处闭包引用同一个 i
funcs = [lambda: i for i in range(3)]
[f() for f in funcs]      # [2, 2, 2]！都指向循环结束后的 i
funcs = [lambda i=i: i for i in range(3)]   # 用默认参数冻结当前值
[f() for f in funcs]      # [0, 1, 2]

四、对象模型：is 与 ==、可哈希、name mangling（6 分钟）

Java 里 == 是引用比较、equals() 是值比较。Python 反过来：== 是值比较（默认调 __eq__），is 才是对象身份比较（≈ Java 的 ==）：

PYTHON — 判等纪律
a = [1]; b = [1]
a == b        # True：值相等 → equals()
a is b        # False：两个不同对象 → Java 的 ==
id(a) == id(b)   # False：id() 是对象身份（≈ identityHashCode）

# 纪律：判等永远写 ==；is 只用于 None / True / False
if x is None: ...        # → if (x == null)
if lst: ...              # truthiness：空容器/0/None 为假

第二个概念：可哈希。Python 对象做 dict 键、进 set，要求可哈希（≈ Java 要求 hashCode 稳定）：数字、字符串、tuple 可以；list、dict、set 不行——所以 {[1,2]: "x"} 直接 TypeError，但 {(1,2): "x"} 合法。frozen dataclass 有真 __hash__，可变对象没有。

第三个：Python 没有 private 关键字，靠约定 + 改名：

PYTHON — 下划线的三种含义
class Account:
    def __init__(self):
        self.owner = "公开"       # → public
        self._balance = 0         # 约定"内部使用"，外部仍能访问（→ @VisibleForTesting 的味道）
        self.__pin = "1234"       # 触发 name mangling：真实名字变成 _Account__pin

acct = Account()
acct.__pin          # AttributeError！
acct._Account__pin  # 改名后的真身（知道即可，别这样访问）
# 双下划线防的是"子类无意覆盖"，不是访问控制

参考实现（先自己写完再看）

# 任务 1 — 闭包计数器
def make_counter():
    count = 0                 # 状态藏在闭包里，不在全局
    def inc():
        nonlocal count        # 没有它，count += 1 会创建新的局部变量
        count += 1
        return count
    return inc

# 任务 2 — 切片循环右移
def rotate(lst, k):
    if not lst:               # 空列表：k %= len 会除零，先挡掉
        return []
    k %= len(lst)             # k 超过长度先取模
    return lst[-k:] + lst[:-k]   # 尾段搬到前面；k=0 时 -0 就是 0，结果恰好是全拷贝

# 任务 3 — Enum 与按值反查
from enum import Enum

class Status(Enum):
    PENDING = "pending"
    PAID = "paid"
    SHIPPED = "shipped"
    CANCELLED = "cancelled"

def from_value(s):
    try:
        return Status(s)
    except ValueError:
        return None

七、检索练习：先答后看（关补全）




  
Q1 · letters = ['a','b','c','d','e','f']，letters[-2:] 得到什么？

  
  
  
  
负索引从尾部数：-1 是最后一个元素，-2 是倒数第二个。letters[-2:] 就是最后两个元素。Java 里取"最后 N 个"要 list.size() - N 手算，Python 一个负号搞定。






  
Q2 · 内层函数要修改外层函数的变量，需要哪个关键字？

  
  
  
  
闭包里对外层（enclosing）变量赋值必须写 nonlocal，否则赋值会创建一个新的局部变量、外层变量纹丝不动（只读引用则不需要声明）。global 是给模块级变量用的，层级不同。






  
Q3 · a = [1]、b = [1]，那么 a == b 和 a is b 分别是？

  
  
  
  
== 对应 equals()，is 对应引用比较（Java 的 ==）。纪律：判等永远写 ==；is 只用于 None / True / False 和"是不是同一个对象"的场景。
