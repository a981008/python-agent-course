一、三个心智转变（知识部分，3 分钟）

Java 程序员写 Python，卡壳的从来不是语法，而是三个习惯。先建立这三个转变，后面的语法都只是映射。

1. 缩进即语法。Java 用 {} 界定代码块，Python 用缩进层级。没有大括号，也没有块结束标记——缩进错了程序就不是你想要的意思。官方规范是 4 个空格[1]。

2. 类型提示是"提示"，不是契约。你熟悉的 List<String> 在 Python 里可以写成 list[str]，语法几乎一样——但 Python 运行时不会校验它[2]。它服务于两件事：IDE 补全和静态检查工具（mypy）。面试手写时加上类型提示是加分项，它展示你理解函数契约。

3. 集合操作靠推导和内置函数，不靠 Stream。Java 里 stream().filter().map() 的活，Python 用一行列表推导完成：[f(x) for x in lst if cond]。这是 Python 手写效率的核心来源，也是本课要建立肌肉记忆的部分。

二、最小知识集：重写一个方法需要什么

对照着看，你会 Java 里已经会的东西 → Python 怎么写：

JAVA — 你要重写的目标public List<String> topOrderIds(List<Order> orders) {
    List<String> result = new ArrayList<>();
    for (Order o : orders) {
        if (o.getAmount() > 100) {
            result.add(o.getOrderId());
        }
    }
    Collections.sort(result);
    return result;
}

用 Python 表达同样的逻辑，只需要五样东西：

构件Python 写法Java 对应
函数定义def top_order_ids(orders):方法签名
类型提示orders: list[Order]、-> list[str]泛型参数
循环for o in orders:增强 for
列表推导[o.order_id for o in orders if o.amount > 100]stream filter+map
排序返回sorted(result)（返回新列表）Collections.sort（原地）

注意两个易错点：sorted() 返回新列表而 lst.sort() 是原地排序——面试里用 sorted 更清晰；属性直接访问 o.amount，Python 习惯不用 getter[1]。

二·补、控制流三件套：break / continue、循环 else、match（4 分钟）

官网第 4 章还有三个控制手段是前面没讲的。它们不是"高级语法"，而是面试手写循环题的常用词汇。

PYTHON — 官网 4.4 / 4.5 / 4.7 节# ① break / continue：语义和 Java 完全一样，只是没有括号
for n in nums:
    if n < 0:
        continue      # 跳过本次，进下一轮
    if n > 100:
        break         # 直接跳出整个循环
    total += n

# ② 循环的 else：循环"正常跑完"才执行，被 break 跳出则不执行
for x in items:
    if x == target:
        print("找到了")
        break
else:
    print("没找到")     # 只有 for 完整跑完、没 break 才走到这里

# Java 里要声明一个 found 布尔变量；Python 用 for-else 直接表达

# ③ match（Python 3.10+）：结构模式匹配 ≈ switch + 解构
match action:
    case {"type": "call", "name": name}:
        dispatch(name)
    case {"type": "final", "text": text}:
        return text
    case _:              # 兜底分支，必须放最后
        raise ValueError("未知动作")

# Agent 场景：LLM 返回 {"type": ...} 字典，match 比一串 if 更清晰

Q4 · for 循环后面的 else 什么时候执行？

for-else 是"没中断才执行"：找到目标后 break，else 不会跑；整个循环没命中才进 else。Java 里要用 found 标志位模拟这个逻辑。

Q5 · match 语句里的 case _ 是什么？

case _ 是通配符模式（wildcard），永远匹配，所以只能放最后。它相当于 Java switch 的 default。

Q6 · continue 的作用是？

continue 只影响当前这一次迭代；break 才是跳出整个循环。两者都不带括号，是语句不是函数。

Q2 · 函数参数上的类型提示默认由谁校验？

Q3 · Java 的 ArrayList 最接近 Python 的哪个内置类型？

list = 可变有序序列，对应 ArrayList；dict 对应 HashMap，set 对应 HashSet。

参考实现（先自己写完再看）

def top_order_ids(orders: list[Order]) -> list[str]:
    """循环版：最接近 Java 直译，面试兜底写法"""
    result: list[str] = []
    for o in orders:
        if o.amount > 100:
            result.append(o.order_id)
    return sorted(result)

def top_order_ids_v2(orders: list[Order]) -> list[str]:
    """推导版：Python 惯用写法，一行表达过滤+映射"""
    return sorted(o.order_id for o in orders if o.amount > 100)


自评清单：① 缩进全是 4 空格？② 两个版本都带了类型提示？③ 循环版用 append、没写出 = [] 声明也行，但你写了更好？④ 推导版注意 sorted() 里放的是生成器，结果一样。
