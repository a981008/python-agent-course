四、re：正则几乎从 Java 平移（5 分钟）

PYTHON — 四个最常用的入口
import re
re.search(r"user=(\w+)", line)     # 找第一处；m.group(1) 取分组；找不到 None
re.match(r"\d+", line)              # 从头匹配（≠ search 全文找）
re.findall(r"\d+", "a1b22")         # ['1', '22'] —— 所有匹配，字符串列表

re.sub(r"\d+", "*", s)              # 替换

# r"..." 原始字符串是正则的标配——免得 \d 写成 \\d
# \w 字母数字下划线；\d 数字；\S 非空白；( ) 分组 group(1)；[...] 字符集；{m,n} 次数

参考实现（先自己写完再看）

import re
from collections import Counter

# 任务 1 — 正则解析单行
def parse_line(line):
    m = re.match(r"(\S+) (\w+) user=(\w+)", line)
    if not m:
        return None
    return {"time": m.group(1), "level": m.group(2), "user": m.group(3)}

# 任务 2 — Counter 统计
def count_by_level(lines):
    c = Counter()
    for line in lines:
        d = parse_line(line)
        if d:
            c[d["level"]] += 1
    return dict(c)

# 任务 3 — 筛选 + 排序
def slow_pay_errors(lines):
    out = []
    for line in lines:
        d = parse_line(line)
        if d and d["level"] == "ERROR" and "action=pay" in line:
            ms = re.search(r"duration_ms=(\d+)", line)
            out.append((int(ms.group(1)), line))
    out.sort(reverse=True)
    return [line for _, line in out]


自评清单：① parse_line 用的是 re.match 还是 search？这里从头匹配，match 就够；② 不匹配的行返回 None 而不是抛异常了吗？③ 排序用 (ms, line) 元组 sort(reverse=True) 时，同行 ms 相同会不会比字符串？想想稳定性。





七、检索练习：先答后看（关补全）




  
Q1 · c = Counter(["a", "b"])，访问 c["不存在的键"] 会怎样？

  
  
  
  
Counter 继承 dict 但重写了缺失键行为：查不到返回 0（计数语义）。普通 dict 查缺失键才抛 KeyError；defaultdict 则会自动建默认值。






  
Q2 · re.findall(r"\d+", "a1b22") 返回什么？

  
  
  
  
findall 无分组时返回匹配字符串列表；有分组时返回分组内容列表。要数字得自己转：[int(x) for x in re.findall(...)]。






  
Q3 · 用 with open(path) as f: 读文件最大的好处是？

  
  
  
  
with 调用文件的 __enter__/__exit__，异常也保证 close——正是第 5 课"让语言替你写 finally"。另外 encoding 恰恰【要】自己显式写，Windows 默认 GBK 是经典乱码坑。
