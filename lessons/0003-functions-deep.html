一、心智模型：函数签名就是接口声明（3 分钟）

Java 里表达"参数可选、调用方式多样"靠方法重载——同一个方法名写好几遍。Python 用一个签名解决：默认参数 + 关键字参数。这是两种语言函数层面最大的差异，也是读 LangChain/FastAPI 源码时到处可见的模式：

JAVA — 重载两个方法
ChatModel call(String prompt) { ... }
ChatModel call(String prompt, double temperature) { ... }
PYTHON — 一个签名全搞定def call(prompt: str, temperature: float = 0.7) -> ChatModel:
    ...

二、完整签名：五样构件

构件语法Java 对应用途
默认参数def f(x, n=3)重载参数可选
关键字传参f(data, n=5)无（Java 按位置）调用处自文档化
仅关键字参数def f(x, *, n=3)无强制调用可读性（* 之后的参数必须写名字）
可变位置参数def f(*args)varargs T...接收任意多个位置参数（元组）
可变关键字参数def f(**kwargs)无接收任意多个具名参数（dict）

重点坑：可变默认参数。默认值在函数定义时创建一次，不是每次调用时新建——所以 def add(item, items=[]) 里所有调用共享同一个列表。正确写法用哨兵值：

错误def add_item(item, items=[]):
    items.append(item)      # 第二次调用时 items 里已经有上次的元素！
    return items
正确def add_item(item, items=None):
    if items is None:
        items = []          # 每次调用新建
    items.append(item)
    return items

lambda：单表达式匿名函数。最常见用途是当排序键——sorted(pairs, key=lambda p: p[1]) 对应 Java 的 Comparator.comparing。超过一个表达式的逻辑就写具名函数，别硬塞。

返回多值：return lo, hi 实际返回元组，调用方 lo, hi = min_max(nums) 解包——这是 Java 里没有的惯用法，面试手写"同时求最大最小"时直接用。

二·补、签名补充：仅位置参数、解包与文档字符串（3 分钟）

官网 4.9 节还有三样构件没讲。前两样和已经学过的 *args/**kwargs 互为逆操作，第三样是框架读取函数用途的入口。

PYTHON — 官网 4.9.3 / 4.9.5 / 4.9.7 节# ① 仅位置参数：斜杠 / 之前的参数只能按位置传
def scale(value, factor, /, *, rounding=2):
    return round(value * factor, rounding)

scale(3, 4, rounding=1)     # OK
scale(value=3, factor=4)    # TypeError：/ 之前不许写参数名

# 用途：参数名没有语义、或以后可能改名时，防止调用方依赖名字

# ② 解包实参（调用侧）：*iterable 与 **mapping
args = [3, 4]
opts = {"rounding": 1}
scale(*args, **opts)        # 等价于 scale(3, 4, rounding=1)

# 和第 2 节的定义侧正好相反：
#   定义 def f(*args, **kwargs) → 把多个实参"收"进 tuple/dict
#   调用 f(*lst, **dct)        → 把容器"拆"成多个实参

# ③ 文档字符串：函数体第一行的字符串字面量
def scale(value, factor, /, *, rounding=2):
    """按 factor 缩放 value，保留 rounding 位小数。"""
    return round(value * factor, rounding)

scale.__doc__     # 被 help() / FastAPI / Pydantic 等框架读取

Q4 · 函数签名里斜杠 / 的含义是？

/ 是"仅位置参数"的分界标记：左侧只能位置传，右侧才是位置或关键字参数。常与 * 配合，形成 "位置-only / 自由 / 关键字-only" 三段式。

Q5 · 调用 f(*lst, **dct) 时，星号的作用是？

定义侧是"收"（多个实参 → 一个 tuple/dict），调用侧是"拆"（一个容器 → 多个实参）。两者符号相同、方向相反。

三、检索练习：先答后看（关补全）

Q1 · def f(x, items=[]) 的隐患是什么？

默认值在 def 执行时求值一次。要每次新建，用 items=None 哨兵 + 函数体内判断。这是 Java 程序员最常踩的坑。

Q2 · def f(amount, *, currency="CNY") 中单独的 * 是什么意思？

* 之后的参数是"仅关键字参数"：f(3.14, "USD") 会抛 TypeError，必须写 f(3.14, currency="USD")。FastAPI/LangChain 源码大量使用。

Q3 · 对 pairs = [("a", 1), ("b", 3)] 按 value 降序排序，正确写法是？

lambda 必须通过 key= 传给 sorted；降序加 reverse=True。写法 a 少了 key=，写法 c 是排序后切片取值，不是自定义排序。

参考实现（先自己写完再看）

def sum_all(*args: float) -> float:
    return sum(args)                    # args 是元组，sum 直接吃

def normalize(amount: float, *, currency: str = "CNY", round_to: int = 2) -> float:
    return round(amount, round_to)      # currency 本函数用不上——签名先行，实现跟上

def top_n(items: list[tuple[str, float]], n: int = 2) -> list[str]:
    return [k for k, v in sorted(items, key=lambda kv: kv[1], reverse=True)[:n]]
